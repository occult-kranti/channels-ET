The paper reads the executed transcript-analysis, transcript-reading and storage-distribution JSON artifacts. Primary analysis units are whole source documents; chunk metadata and time bins are not independent model observations. ASR uses Systran/faster-whisper-tiny.en, revision beginning 0d3d19a32d33 (the full commit and official file hashes are retained in the model manifest), with faster-whisper v1.2.1, CTranslate2 v4.8.3 and PyAV v16.1.0 on CPU. The private local archive verifies separate single-link copies; it does not change source IDs or analytical weights. The public source package compiles without those private files because it includes the frozen generated evidence. Full analytical reproduction requires the source pipelines and exactly matching private snapshots.
