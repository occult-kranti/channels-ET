# Source-grounded transcript research paper

This new living report integrates the actually retained twenty publisher recordings, their unverified ASR, sixteen separately published authored/transcript documents, executed lexical/topic/cluster/network analyses, selected-window model-assisted readings and source/storage distributions. It preserves the earlier research papers and model experiments.

The manuscript date is 23 October 2026 in America/New_York; source/execution receipts retain their UTC dates, including 24 October. Nineteen Bashar-related publisher recordings and one Athina/Ashtar episode are not twenty independent mediums. Written-source labels, dictionary matches, topic components, publishing accounts and verified speakers are distinct fields. No new YouTube download or biological/physical-origin finding is claimed.

Build from the repository root after the source owners have produced their actual result artifacts:

```bash
bash research/transcript-paper/build.sh
python research/transcript-paper/scripts/verify.py
```

`generate.py` reads source/result JSON, checks source-identity joins, copies actual numerical figures and writes the tables and exact input manifest. It refuses missing evidence. The build uses the unchanged official AAAI2027 preprint style, the retained verified bibliography and fixed timestamp metadata. The prepared environment supplies TeX, its pinned font tree, BibTeX and PDF inspection tools. No network, collection or model training is part of this build.

`channels-et-transcript-paper.pdf` is the full paper. `channels-et-transcript-source.zip` is a standalone Overleaf-compatible compilation bundle: upload the ZIP and compile `main.tex` with pdfLaTeX/BibTeX. The bundle includes all generated tables/figures, bibliography and official style; it excludes raw source text, media, browser data and weights. It compiles from frozen generated evidence. Recomputing the source analyses additionally requires the matching lawful private source snapshots and their source pipelines; this is not a public redistribution of a full transcript corpus.

The local verifier compiles the exact ZIP in isolation, compares extracted page text, checks current input hashes/fonts/citations/layout and renders every page. Exact-candidate visual inspection and three iterative agent-review receipts are recorded separately. Model-agent review is not independent human peer review. Human authorship, institutional/rights determinations, speaker and construct validation, and venue-specific compliance remain TBD. The extended living report is not submitted or accepted.

Only this directory is written by the manuscript pipeline. Earlier manuscript, bibliography and vendor sources are read and copied without modification. Upstream source/result artifacts stay owned by their respective workstreams. The generated input manifest and artifact manifest identify the exact evidence and PDF/ZIP candidate; a receipt for an earlier hash does not certify a later candidate.
