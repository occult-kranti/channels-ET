# Panel decisions and targeted review

This records actual asynchronous AI-agent work. Five panel roles covered speech
engineering, literature, computational methods, source/question reading and
critical interface design. A separate independent auditor froze queries and
checked source readings and executions; the root agent integrated the release.
No named human expert, institutional review board or external peer review is
implied.

| Milestone | Objection or finding | Action and evidence |
| --- | --- | --- |
| Scope and feasibility | A current model-card benchmark does not establish local accuracy; disk is nearly full | Selected a pinned official Parakeet release, downloaded into RAM, checked hashes, timed a 30-second CPU pilot and preserved old models/audio |
| Literature identification | Several unrelated approaches use “sleep” | Matched Google's October 2026 blog to arXiv:2606.03979v2; kept weight-updating Sleep separate from external card/index consolidation |
| Frame design | Combining overlapping older studies inflates observations | Frozen 25-edition/47,280-word frame, exact-body/family checks; separate 228-unit study unchanged |
| Query evaluation | Card-author questions are answer-informed | Independent author froze four source-informed queries before card/ranking inspection; retained incomplete relevance and AI-label limitations |
| Question semantics | Punctuation and similarity cannot identify documentary questions or agreement | Separated eight analyst questions from five printed-question paraphrases; comparisons require source, proposition, conditions and time |
| Source review | Some summaries omitted decisive qualifications or used an imprecise locator | Rebound the Lyssa skills claim, scoped Mary's distrust, retained Contact's relative-year prediction, retained Pamela's specific qualifiers, and completed a truncated ASR support turn in fresh annotation editions |
| Retrieval execution | Full-list RRF mechanically favors card-covered sources | Retained initial results, documented the inequality, and added a single fixed top-five repair after the first run with explicit post-hoc status |
| Representation review | A two-dimensional map and TF-IDF terms can be mislabeled as word meaning | Added source keys, projection variance/distortion and a separate actual contextual-token experiment; kept lexical term weights, document vectors and token states distinct |
| Interface review | A global SVG style hid semantic squares, and an inspected title could become stale | Corrected both defects and added actual-data keyboard/mobile/overlay checks |
| Speech execution | Missing feature dependencies and unchecked timeouts could make feasibility misleading | Preserved the failed first attempt, installed pinned dependencies into RAM only, added outer hard timeouts and complete-encoder guards, then executed the accepted paired benchmark |
| Benchmark review | One baseline output is highly repetitive; raw timestamp overruns must stay visible | Retained every output, added a disclosed post-hoc repetition screen and raw timing diagnostics; no word-accuracy claim |
| Full-recognition extension | A new decoder precision/context could confound edition comparison | Verified old canonical S16 waveform hashes before float conversion; kept chunking/context differences explicit and preserved all old text/card bindings |

The first milestone established scope and prospective pilot choices. The next
implemented and challenged source, numerical and interface outputs. The final
milestone checks actual execution, affected artifacts and deployment. These are
review iterations with observable corrections, not manufactured unanimous
expert opinions.

Independent records are retained privately by role: source/card integrity,
numerical representation refits, retrieval-method reproduction, retrieval-policy
arithmetic, model/PCM/output checks, contextual-token geometry and rendered
scientific interpretation. Reconstructed proof metadata after a private filename
collision is explicitly labeled; no numerical output was altered by that
bookkeeping correction. The report and interface cite performed checks
separately from unmeasured human accuracy and unresolved hypotheses.

Full-recording completion, paired sensitivity, final public input hashes and
deployment are recorded in the final release receipts. An active process or
prepared script is not counted as a completed recording.
