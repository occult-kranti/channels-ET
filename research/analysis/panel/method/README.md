# Independent methods panel

These are actual model-agent review records from `/root/method_panel`, not human peer review or certification. Review documents bind conclusions to data hashes. The numerical verifier was frozen before producer code was inspected; its hash is recorded in the first review. Vector recomputation uses exported vectors and independent aggregation.

Round 1 checks describe the first title-only build. Round 2 adds freshly retrieved metadata and actual MiniLM title/caption vectors. Counts differ by input snapshot. The final review will record final-input checks after repairs. Local verifier scripts preserve the executed workspace paths as audit records; the project's maintained validation commands are documented in the parent analysis README.

Raw captions are deliberately absent. The source-files hash and normalized-text hash need distinct labels. Interim caption-rate checks used an underspecified tokenizer and are not classified as numerical defects until the producer's exact token definition is reconciled.
