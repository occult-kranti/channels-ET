## Pipeline

1. **Select and discover.** Rebuild `selection.py` into a new output directory; review typed context quotas and missing candidates. Exact upload IDs are globally deduplicated. Context associations are not automatically verified speaker identities. Fresh enumeration must use restored ordinary source access and enter the existing metadata-only import path.
2. **One real acquisition pilot.** With actual source access restored, obtain a runner-created watch probe for the current supported runtime configuration, then target a single source with `run-one --kind metadata --source-id youtube:ID`, followed by `run-one --kind video --source-id youtube:ID`. A metadata response, signed URL or small HTML error file does not count as a downloaded video. Actual streams, duration, height, source ID and hashes must validate before expansion.
3. **Bounded parallel batches.** Only after that source's complete acquisition is working, use `run-bounded --selection .../proposed-batch.json --workers 2 --max-jobs N --max-video-height 480` with the current runtime observation. The allowlist restricts the existing ledger; it neither grants admission nor resets failed jobs/cap slots. Optional captions may be unavailable while video continues. Rate limits and global transport/authentication failures pause the configuration; no automatic bulk retry follows a denial. Metadata/probe freshness, disk reservations and the 6GiB free-space reserve remain active.
4. **Verified export.** `export_verified.py` reads the original ledger without mutating it and emits private `verified-media.json` plus a hashed proof. It excludes unverified, mismatched, missing, silent, short, unsupported-format or unaccounted Bashar media. Archived metadata is checked against its acquisition proof rather than wrongly requiring it to remain fresh forever.
5. **Audio and ASR.** `audio.py` validates the exact source, decodes audio, records explicitly defined signal metrics, and produces machine transcripts with timecodes. English-only models must not silently process known non-English sources. Known language, model/settings hashes, mixed speakers and recognition limitations stay visible. See [AUDIO.md](AUDIO.md).
6. **Organized private storage.** `storage.py` uses finalized hash-bound artifacts only. Local archive copies and file-level resume verify source and destination bytes. The explicit hardlink mode used for this batch organizes media without duplicating the large originals; source and archive paths share stored bytes, so this is not an independent backup. Source media, audio, transcripts, analysis and verification receipts remain linked by source ID. Optional future Drive transfer requires an actual authorized remote and authenticated account/quota, but is not a prerequisite for the user's current local-cloud choice. See [STORAGE.md](STORAGE.md).
7. **Analysis.** Inspect real transcript passages and timestamps; keep keyword counts and lexical similarities distinct from semantic agreement, speaker attribution, prediction accuracy and evidence for an extraterrestrial origin. A publisher transcript and ASR of the same recording are two versions of one source, not independent mediums.
