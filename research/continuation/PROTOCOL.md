## Research and deliverables

The unit hierarchy remains practitioner, publishing account, attributed entity,
upload, original performance, text artifact, question candidate, answer candidate
and model output. None of these units substitutes for another. The study concerns
publicly attributed discourse; computational resemblance does not identify the
physical source or truth of a claim.

This phase will produce a current literature register, a complete living LaTeX
paper and importable source ZIP, regenerated scientific figures/tables, a research
dashboard, an organized data/source package, executable resumable collection
software, and actual local-model feasibility/benchmark evidence. Human authorship,
affiliations, institutional determination, construct validity, release rights and
submission compliance remain explicit TBD items where unresolved.

## Collection and resources

Current resource inspection reports a four-CPU cgroup quota, about 32 GiB RAM,
about 30 GiB free workspace storage and no `nvidia-smi`. Package/runtime probes
and actual model loading will establish CPU/CUDA availability more directly.
Model files, caches, raw captions and video files belong outside Git. Generated
weights must not be presented as a generally valid domain model on the basis of
a small optimization run.

The environment's desired network mode changed from restricted to unrestricted.
Observed enforcement remains unknown. New ordinary requests determine access for
each source. A current YouTube watch preflight still receives proxy CONNECT 403;
an author transcript endpoint also returns 403. These are retained access outcomes,
not evidence of absent content. Official scholarly PDFs and Hugging Face metadata
are accessible in this phase. Preserve TLS, the inherited session route, failure
ledgers and stop-on-block behavior. Do not use proxy rotation or credential/private
access workarounds. No successful crawl is inferred from software installation.

Collection code must support explicit channels, complete pagination where exposed,
resumable checkpoints, per-upload status, offered-caption selection, disk quotas,
and a media dry run before a download. A bounded pilot precedes a broad batch.
“All channel videos” is a queue objective; completeness requires an actual final
enumeration/availability ledger and cannot be established after an access denial.

## Local-model comparison

Use a pinned official model/revision/license and verified artifacts. Inspect current
Qwen families before choosing a CPU baseline. A small runnable model is a resource
baseline; it is not automatically the state of the art. Record actual hardware,
software versions, input lengths, seeds, decoding, wall time, memory and failures.

Compare a lexical retrieval baseline, closed-book local generation, retrieval-
augmented generation and, if feasible, a bounded Qwen LoRA run. Training and test
examples must be grouped by source upload and conservative duplicate/retrieval
families rather than randomly splitting individual questions. Keep evaluation
answer gists out of the training set and retrieval evidence when testing held-out
source generalization. Record exactly which task each retrieval setup evaluates.

The retained 949 Q&A candidates are AI digest paraphrases from one practitioner
context, not 949 validated transcript turns. Lexical overlap, retrieval hits,
citation formatting and latency are reproducible diagnostics; none is a validated
human semantic score or answer-truth measure. Negative results and failed training
must be retained. A tiny pilot cannot establish that fine-tuning beats RAG, that a
model is useful across mediums, or that model agreement corroborates a claim.
