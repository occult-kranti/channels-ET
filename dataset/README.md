This folder is the entry point for the dataset work in the existing
`occult-kranti/channels-ET` repository. No new repository is required.

The frozen release has **683 selected publications, 694 text editions,
1,599,556 selected words and 26 publisher contexts**. The discovery inventory has
2,812 observed YouTube identifiers. These are distinct units. Uploaded channel
totals remain unknown and direct YouTube downloads remain zero.

`channels.csv` records the frozen source-frame state; its unfilled analysis fields
are not zeros. `tables/channel-profile.csv` and the dashboard analysis module
record the completed model run. All public artifacts remain in one canonical
location under `dist/dataset-submission/`, with hashes in its release manifest.

The user has authorized public storage of raw sources. Third-party audio and
complete transcript bodies still require their own redistribution basis. Public research files can be cloned normally;
the archive documentation records the separately verified storage/access status.
