# Full-source archive

The project now uses the existing `channels-ET` repository; the separate-repository
plan has been superseded. Public code, metadata, plots, tables and paper live in
this repository. The user has now authorized public storage of complete audio, transcripts and
source snapshots. Source-specific redistribution terms remain separate from this
storage preference.

The retained-root inventory contains 39,327 logical file paths and 36,413 unique
content objects, totaling 17,806,101,487 deduplicated bytes. A separate verified
corpus/analysis supplement contains the complete selected text database, all 694
edition bodies and final numerical outputs. Logical file paths are not counts of
videos, publications or transcript documents.

Storage in this existing repository uses public research folders and, when
verified, release assets. Original-source licenses and the release upload route
are being checked before full-source publication. The [live archive receipt](../../dist/dataset-submission/archive.json)
reports actual verified remote assets and bytes; zero means no verified transfer.
The [archive tools](../../research/dataset-submission/archive/README.md) preserve
source hashes, bounded staging, resumable uploads and restore verification.

The public website and paper do not depend on completion of this separate raw
archive transfer. Existing local originals are preserved.

The [public object index](../../dist/dataset-submission/archive-objects.jsonl)
exports every retained object hash, byte size, alias count and verified transfer
state. [Its summary](../../dist/dataset-submission/archive-object-summary.json)
reconciles all 36,413 objects and 39,327 aliases. It contains no original bodies
or local filenames; publishing this index is not uploading those source files.

The [bounded source-rights review](../../research/dataset-submission/PUBLIC-SOURCE-RIGHTS.md)
records the actual inspected terms. No blanket full-archive redistribution license
was established. GitHub Release uploads also returned HTTP 401 for both CLI and
official REST attempts, including tiny synthetic files. Public research and this
object index are committed normally through Git; full-source remote transfer
remains incomplete.
